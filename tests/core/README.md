# tests/core

Tests unitarios del núcleo (`core/`): `recursos` (tabla de `calcular_hilos`,
`techo_hilos`, `objetivo_activos`), `paralelo` (`PlanLista`, `Ejecutor`),
`resultado` (`Resultado`/`EstadoResultado`/`Cancelado`), `formato` (humano/duracion),
`cli` (`correr_cli`), `reanudable` (`RegistroReanudable`: JSONL, inspeccionar,
compactación), `control` (parada común), `registro` y `ejecucion`.

**No requieren Tkinter.**
